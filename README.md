Maze Generator (Java | OOP | Algorithms | JavaFX)

A grid-based maze generator implemented in Java using object-oriented principles. This project generates random mazes using Depth-First Search (DFS) and stack-based backtracking, and allows interactive exploration with real-time trail tracking and a timer.

Features

Random Maze Generation: Each game generates a unique maze using DFS and stack-based backtracking.

Interactive Player: Move through the maze using arrow keys, with walls enforcing valid paths.

Trail Tracking: Shows the path the player has taken.

Timer: Tracks the time from the first move until reaching the goal.

Clean OOP Design: Maze logic is decoupled from rendering, making it flexible and maintainable.

JavaFX Rendering: Smooth graphics without external libraries.

Tech Stack

Java

Object-Oriented Programming (OOP) principles: encapsulation, abstraction, modular design

JavaFX for UI and interactive graphics

Algorithms: DFS and stack-based backtracking

How to Run

Clone the repository:

git clone https://github.com/yourusername/maze-generator.git


Open the project in your favorite Java IDE (IntelliJ, Eclipse, etc.).

Run MazeApp.java.

Use the arrow keys to move the player from the start (green) to the goal (blue).
